# Computer Vision & Edge Video Analytics Module

## Purpose
The **Computer Vision** module processes live CCTV and thermal camera streams for real-time safety inspection:
- PPE Compliance (Hardhat, High-vis vest, Safety boots detection)
- Restricted Zone Geofence Breach Detection
- Vehicle-Pedestrian Proximity Hazard & Collision Alerting
- Rockfall & Slope Movement Visual Optical Flow

## Phase 1 Status
Camera registry and RTSP/HLS stream metadata database schema operational. Deep learning edge pipelines (YOLOv8/v10, ByteTrack) will be attached in subsequent phases.
