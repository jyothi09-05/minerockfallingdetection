# MineMind AI — Control Room Operator User Guide

## 1. Navigating the Unified Command Center
1. **Log in** with your assigned role credentials (e.g., `ROLE_SAFETY_OFFICER` or `ROLE_MINE_MANAGER`).
2. **Operations HUD**: Real-time 2D/3D map displaying active haul trucks, workers, shovels, and sensors.
3. **Layer Filtering**: Toggle vehicles, workers, equipment, sensors, and risk heatmap overlays using the top-left toolbar.
4. **Entity Inspection**: Click on any vehicle, sensor, or worker on the canvas to open their real-time telemetry inspector.

## 2. Managing Incidents
- Navigate to **Incident Management** (`/incidents`).
- Review the 7-stage lifecycle (`Detected` -> `Classified` -> `Investigating` -> `Escalated` -> `Responding` -> `Resolved` -> `Closed`).
- Review attached evidence, assign investigators, and advance the stage.

## 3. Emergency Evacuation Simulation
- Open **Emergency Response** (`/emergency`).
- Trigger any of the 8 simulated scenarios (e.g. Rockfall on Bench 1350).
- Review the designated primary egress corridor, safe muster point, and automated action plan checklist.

## 4. Local AI Intelligence Assistant
- Open **AI Mining Assistant** (`/ai-assistant`) or click the **AI Copilot** drawer in the command center.
- Switch between 5 specialist roles (Safety Officer, Geotechnical Engineer, Maintenance Specialist, Pit Dispatcher, Mine Manager).
- Ask questions regarding SOPs, radar slope velocity, or blast clearance zones.
