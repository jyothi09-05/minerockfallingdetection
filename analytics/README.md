# Analytics & Operational Intelligence Module

## Purpose
The **Analytics** module computes key operational KPIs:
- Overall Equipment Effectiveness (OEE)
- Fleet Availability, Utilization, and Mean Time Between Failures (MTBF)
- Ore vs. Waste Stripping Ratio and Daily Extraction Volume
- Environmental & HSE Incident Frequency Rates (LTIFR, TRIFR)

## Phase 1 Status
Baseline operational aggregations and telemetry endpoints established in Java core and Python AI.
