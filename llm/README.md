# Local LLM Agent Module

## Purpose
The **LLM** module runs offline, quantized open-weights Large Language Models (e.g., Llama 3 / Mistral via llama.cpp or vLLM) on local GPU/CPU hardware.

## Target Responsibilities
- Mining Safety Copilot & Emergency Incident Advisor
- Shift Handover automated summarization
- Geotechnical hazard report generation
- Natural language query to SQL (NL-to-SQL) for mine operations metrics

## Phase 1 Status
Local model directory scaffolding initialized (`data/models/`). Inference engines and agent tool calling will be activated in later phases.
